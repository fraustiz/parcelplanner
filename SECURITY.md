# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/fraustiz/parcelplanner/security/advisories/new).
Include what you found, how to reproduce it, and what an attacker could do
with it. You will get an answer within a week.

## Scope

In scope: the code in this repository and the instance at
https://parcelplanner.app (short links, link previews, the suggestion box).

Out of scope: denial of service by sheer traffic, reports from automated
scanners without a working proof, and the game itself.

## Supported versions

Only the latest commit on `main`, which is what parcelplanner.app runs.
